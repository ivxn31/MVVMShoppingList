## Uso
Compilar el proyecto en Android Studio.

## Características

- Aplicación móvil para organizar listas de compras de forma sencilla.
- Permite agregar productos indicando su nombre y cantidad.
- Facilita aumentar o reducir la cantidad de cada producto.
- Permite eliminar artículos de la lista.
- Guarda la información para conservar la lista dentro de la aplicación.
- Cuenta con una interfaz clara, simple y fácil de utilizar.
- Incluye botones de acceso rápido para las acciones principales.
- Valida que la información necesaria esté completa antes de agregar un producto.
- Diseñada para ofrecer una experiencia práctica desde dispositivos Android.
- El proyecto demuestra conocimientos de desarrollo móvil, organización de código y diseño centrado en el usuario.
- Compatible desde Android API 21.
- Separación por capas: UI, ViewModel, repositorio, DAO y entidades.
- Pruebas unitarias e instrumentadas configuradas.

- Kodein como inyector de dependencias
